description: Refactor shell scripts and manifests for clarity and maintainability

Refactor the specified files focusing on:

1. **DRY**: Extract repeated patterns into functions or templates
2. **Error handling**: Add proper error messages and cleanup traps
3. **Readability**: Consistent naming, commenting complex logic
4. **Idempotency**: Ensure scripts can be re-run safely

Do not change behavior. Preserve all existing functionality.
